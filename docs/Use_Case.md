# Use Case Summary
Actors: Admin, Inventory Manager, Sales Staff, Purchase Officer.

Common: Register, Login, Logout, Remember Me cookie, session authentication, own profile view/edit/delete, own password change, personalized dashboard.

Admin: User management, Product management, Category management, Reports.
Inventory Manager: Stock In/Out, Stock Adjustment/Monitoring, Low Stock, Stock History.
Sales Staff: Customer management, New Sale, Sales History.
Purchase Officer: Supplier management, New Purchase, Purchase History.
